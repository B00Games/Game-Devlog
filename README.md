# B00 Games — Game Devlog

This repository contains development updates, screenshots, and progress notes from **B00 Games' first project**.

The game is currently in early development and is being built in **Unreal Engine**.

## Current Development Areas

- Core interaction systems
- Inventory and item inspection
- Interactive doors and key systems
- Story development
- Level design
- Environment blockout
- Family House layout and mansion construction

## Current Stage

**Early Development — Level Design & Blockout**

The current focus is on building the main Family House location and refining the gameplay systems needed for Chapter 1.
