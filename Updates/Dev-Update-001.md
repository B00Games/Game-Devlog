# Dev Update #001 — Project Foundations

Welcome to the first development update for B00 Games' first project.

The game is currently in early development and is being built in Unreal Engine.

This first update is a retrospective overview of the main systems and development work completed so far.

## Core Interaction System

The project now has a reusable interaction system that allows the player to interact with objects using a camera-based trace.

This system is used for items, doors, keys, and other interactable objects.

## Inventory System

A functional inventory system is already implemented.

Current features include:

- Item pickup
- Dynamic inventory slots
- Item selection and deselection
- Item names and descriptions
- 3D item inspection
- Item rotation
- Zoom controls

The first test item implemented with the system was the Office Key.

## Door and Key System

A reusable door system has also been completed.

Current features include:

- Locked and unlocked door states
- Required key checks
- Smooth opening and closing
- Interaction prompts
- Door handle animation
- Synchronized handles on both sides
- Basic anti-spam protection during animations

The door asset has also gone through several visual improvements, including recessed panels, a frame, handles, lock components, and dark materials.

## Story and Level Design

Development has now moved heavily into story-driven level design.

The first major playable location is the Family House, a large old villa that forms the main setting of Chapter 1.

The house is currently being designed with:

- A central grand foyer
- Left and right wings
- Multiple floors
- An attic
- Service areas
- A hidden route leading toward an underground laboratory

The current focus is on creating a believable layout that supports the story and gameplay progression before committing to a more detailed Unreal Engine blockout.

## Current Mansion Blockout

The current blockout work includes:

- Grand foyer
- Living room
- Main hallway
- Kitchen connection
- Early ground-floor layout planning

The mansion is still in an early blockout stage and room dimensions, positions, and connections may continue to change.

## Current Development Stage

**Early Development — Level Design & Blockout**

The next steps are focused on continuing the ground-floor mansion layout and refining the overall scale and structure of the Family House.

More development updates, screenshots, and progress notes will be added as the project continues.
